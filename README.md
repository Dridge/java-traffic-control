# Java Traffic Control

## Service to end point tracking

A simple project illustrates a basic demo of how you could track the end points
for a specific service.

Registering and deregistering hostnames and ports that serve that service.

## Goal

To use modern Java version to produce a working example and refresh concepts and 
pitfalls

## Assistance

It wouldn't be realistic if AI was not involved, used to help troubleshooting
or iterate over the initial skeleton idea.

TDD was used, to keep focused on specific problems and not over-engineer this
small simple example.
